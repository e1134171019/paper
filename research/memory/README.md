# Research Memory Ledger

這個目錄不是聊天備份，而是「可延續研究狀態」。

目的：讓下一次 ChatGPT / Codex / 其他 AI 或人類研究者，不需要重讀整段對話，也能知道：

1. 我們目前研究什麼。
2. 哪些想法已被文獻做過，不能再當新穎性。
3. 哪些是目前仍值得驗證的候選缺口。
4. 哪些結論只是工程推論，哪些有直接文獻證據。
5. 下一步應該查什麼、模擬什麼、如何否證。

## 記錄原則

- ChatGPT 對話 = 探索、推理、暫時假設。
- GitHub = 經過整理後的正式研究狀態與可追溯紀錄。
- 不把整段聊天原文直接當「記憶」。只保留：問題、證據、決策、被排除方向、未解問題、下一步。
- 每次重大研究轉折都要留下日期與原因。
- 所有「世界上沒人做」都禁止直接記錄；只能寫「目前檢索尚未找到完全重合先行研究」。
- 文獻直接證據與工程推論必須分開。

## 檔案

- `CURRENT_STATE.md`：目前研究主線、邊界、已知結構與候選缺口。
- `DECISION_LOG.md`：研究方向如何一路排除與收斂。
- `PRIOR_ART_BOUNDARY.md`：已知先行研究、不能再宣稱新穎性的項目。
- `HANDOFF.md`：給下一個 AI / 下一次工作階段的最短續接內容。

## 更新規則

每次研究結束前至少更新：

1. 新找到的 closest prior art。
2. 哪個假設被推翻或縮小。
3. 目前最強候選研究問題。
4. 下一輪檢索字串與驗證條件。
5. 任何數值結論的適用條件。
